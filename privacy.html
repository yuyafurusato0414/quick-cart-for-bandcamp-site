日本語

Quick Cart for BandcampはBandcamp向けの非公式Chrome拡張です。カード情報・住所・パスワードを保存しません。決済はBandcampや決済会社の公式画面でユーザーが確認します。

Bandcampのカート・ウィッシュリスト・金額・残高・試聴情報を取得し、ユーザーが選んだカート変更・ウィッシュリスト操作をBandcampへ送ります。画像・音声はbcbits.comから取得します。許可された独自ドメインのBandcampストアでも動作します。

残高チャージでは公式のギフトカード購入画面を表示します。購入金額を選び、本人への送付先を公式フォーム内で確認します。購入完了後、ユーザーがメールから手入力したコードをBandcampへ送り、公式フォームで金額と登録先を確認します。残高登録は、ユーザーがコードを入力して「残高に登録」を押すと公式フォームから行います。本人確認や通貨選択を省略しません。音楽購入は自動実行しません。Gmailへの接続やメールの検索・読み取りは行いません。

設定のON/OFFはchrome.storage.sync、有効にしたサイトはChromeの権限に保存します。短期のカート再表示フラグはchrome.storage.local、購入途中のカート照合情報・金額・アカウントID・タブ番号・処理状態は有効期限付きのchrome.storage.sessionに保存します。コードはメモリでのみ扱い、ストレージやログに保存しません。メール本文や受取先アドレスを開発者へ送りません。

任意のバグ報告はGoogleフォームを開きます。閲覧ページURLやログを自動添付しません。ユーザーが送信した内容は開発者の非公開回答シートで改善のため確認し、公開転載しません。個人情報やコードを記入しないでください。解析・広告・AIは使いません。

English

Quick Cart for Bandcamp is an unofficial Chrome extension. It does not store card details, postal addresses or passwords. Users confirm payment on official Bandcamp or payment-provider screens.

The extension retrieves Bandcamp cart, wishlist, price, balance and preview information, and sends user-selected cart/wishlist changes to Bandcamp. Images and audio come from bcbits.com. Custom-domain Bandcamp stores are accessed only with site permission.

Top-up displays the official gift-card purchase form. Users select an amount and confirm self-delivery in the native form. After confirmed payment, users manually enter the code from their email. The code is sent to Bandcamp for native amount/account validation; registration proceeds through the official form when the user enters the code and clicks Add to balance. Authentication and currency choices are preserved. Music is never purchased automatically. Version 2 does not connect to Gmail or search/read email.

On/off settings use chrome.storage.sync. Enabled sites are stored as Chrome permissions. A temporary cart-reopen flag uses chrome.storage.local. Expiring cart/account matching information, amounts, tab IDs and flow state use chrome.storage.session. Codes are processed only in memory and are not saved in storage or logs. Message bodies and delivery addresses are not sent to developer servers.

Optional bug reports open Google Forms without automatically attaching page URLs or logs. Submitted reports are reviewed in the developer's private response sheet and are not publicly reposted. Do not include personal information or codes. No analytics, advertisements or AI.
